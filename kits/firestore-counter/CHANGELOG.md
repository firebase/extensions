- feat: add the `DATABASE_REGION` parameter, which places the functions in the Cloud Run region derived from your Firestore database location. Regional locations pass through unchanged and the multi-region locations map to a region inside them (`nam5`/`nam7` to `us-central1`, `eur3` to `europe-west1`) instead of failing the deploy. Requires firebase-tools >= 15.28.0; with an explicit empty `DATABASE_REGION=` line in `.env` the functions declare no region and the Firebase CLI resolves one at deploy time, as before; omitting the line fails a non-interactive deploy. Changing the value on an existing instance deletes and recreates the functions.
