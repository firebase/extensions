- feat: add the `DATABASE_REGION` parameter, which places the function in the Cloud Run region derived from your Firestore database location. Regional locations pass through unchanged and the multi-region locations map to a region inside them (`nam5`/`nam7` to `us-central1`, `eur3` to `europe-west1`) instead of failing the deploy. Requires firebase-tools >= 15.28.0; with the parameter unset the function declares no region and the Firebase CLI resolves one at deploy time, as before. Changing the value on an existing instance deletes and recreates the function.
- fix: `ENABLE_DISCUSSION_OPTION_OVERRIDES` and `ENABLE_GENKIT_MONITORING` accept the extension's `yes` / `no` values again. The kit had declared them as boolean params, which only count the literal `true` as enabled, so a `.env` copied from an installed extension instance carried `yes` and silently left per-discussion overrides and Genkit monitoring off. Both are now the extension's labeled `Yes` / `No` selects and are read the same way the extension read them.
