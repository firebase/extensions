The function declares the parameter and the Firebase CLI substitutes the value at deploy time, so it applies to the deploy that sets it. The value is required: a non-interactive deploy fails while it is missing from `.env`, and it reaches Cloud Run as written, so it has to be one of the offered regions. Changing the value on an existing instance deletes and recreates the function. Upgrading an existing install: add `DATABASE_REGION` to your `.env` before your next deploy. A blank entry is rejected at deploy-time discovery rather than reaching Cloud Run.
