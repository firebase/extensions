- **BREAKING** feat: add the `DATABASE_REGION` parameter, which places the function in your Realtime Database instance's region, as a 2nd gen database trigger requires. The function declares the parameter and the Firebase CLI substitutes the value at deploy time, so it applies to the deploy that sets it. The value is required: a non-interactive deploy fails while it is missing from `.env`, and it reaches Cloud Run as written, so it has to be one of the offered regions. Changing the value on an existing instance deletes and recreates the function. Upgrading an existing install: add `DATABASE_REGION` to your `.env` before your next deploy.
