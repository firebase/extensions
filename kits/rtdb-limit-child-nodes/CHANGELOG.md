- feat: add the `DATABASE_REGION` parameter, which places the function in your Realtime Database instance's region, as a 2nd gen database trigger requires. Requires firebase-tools >= 15.28.0; with an explicit empty `DATABASE_REGION=` line in `.env` the function declares no region and the Firebase CLI resolves one at deploy time, as before; omitting the line fails a non-interactive deploy. Changing the value on an existing instance deletes and recreates the function.
