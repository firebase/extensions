- fix: stop deploying functions to the `DATABASE_REGION` value. Firestore multi-region locations (`eur3`, `nam5`, `nam7`) are not Cloud Run regions, so any multi-region database made every deploy fail. The `DATABASE_REGION` parameter is removed; the Firebase CLI resolves each function's deploy region itself and always pins the Firestore trigger to the database's own region. Set `FIREBASE_FUNCTIONS_DEFAULT_REGION` when deploying to choose the function region. `ExportConfig.location` is removed from the library surface.
