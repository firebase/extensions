- feat: add the `BUCKET_REGION` parameter, which places the function in the Cloud Run region derived from your Cloud Storage bucket location. Regional locations pass through unchanged and the multi-region locations map to a region inside them (`us` to `us-east1`, `eu` to `europe-west1`, `asia` to `asia-east1`) instead of failing the deploy. Dual-region locations are not mapped. Requires firebase-tools >= 15.28.0; with the parameter unset the function declares no region and the Firebase CLI resolves one at deploy time, as before. Changing the value on an existing instance deletes and recreates the function.
- fix: restore the extension's `Enabled` / `Disabled` option labels on the `ENABLE_AUTOMATIC_PUNCTUATION` deploy-time prompt. The stored values are unchanged (`true`/`false`), so this is a label-only fix and no `.env` from an earlier deploy needs editing.
